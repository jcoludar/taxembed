# Paper figures — Poincaré taxonomy embeddings

Scaffolding for the results writeup. Figures are regenerated from on-disk artifacts by the scripts in
`scripts/`; nothing here is hand-drawn. Regenerate all with the commands listed per figure.

## Key result (locked 2026-06-04)

The canonical recipe (eff-batch 2048 · n_neg 300 · lr 0.001 · cosine warm-restart-on-phase, softmax +
euclidean-param + curriculum) clears **EXCELLENT separation at every rank at full metazoa scale
(498,246 nodes)**:

| Rank | Separation (mean±std, 5 seeds) | kNN purity@10 | lift over chance |
|------|-------------------------------:|--------------:|-----------------:|
| phylum | 2.60 ± 0.01× | 0.997 | 2.1× |
| class  | 3.85 ± 0.01× | 0.997 | 3.2× |
| order  | 6.68 ± 0.01× | 0.995 | 17.9× |
| family | 10.30 ± 0.01× | 0.919 | 216.6× |

depth↔norm correlation +0.984 (Pearson) / +0.998 (Spearman). The separation is genuine **angular**
structure, not a radial/Poincaré-metric artifact: kNN-purity (a local, radius-independent neighbour-
identity measure) sits at 92–99% same-clade, vastly above chance, and rises toward finer ranks.
Sources: `artifacts/tags/metazoa_lower_lr_bigger_batch/analysis_final_seeded/` and `.../knn_purity/`.

## Figures

### `metazoa_separation_trajectory.{png,pdf}` — the headline figure
Per-rank separation ratio vs. epoch (ep10→200) with the depth↔norm correlation on the twin axis. Tells
the **radial-flat / lateral-climb** story: depth↔norm is pinned at +0.98 from ep10 (the radial frame is
in place early) while per-rank separation climbs from ~1× to 2.6–10.3× as the curriculum widens its
depth-difference window (transitions marked at ep40/80/120). Earlier recipes collapsed at the ep80
(dd≤18) transition; the four-lever recipe climbs straight through.

Regenerate:
```
.venv/bin/python scripts/figure_separation_trajectory.py \
  --summary artifacts/tags/metazoa_lower_lr_bigger_batch_summary.tsv \
  --title "Metazoa (498k nodes) — canonical recipe (Exp 1)" \
  --transitions 40 80 120 \
  --out paper/figures/metazoa_separation_trajectory
```

### `metazoa_umap_phylum_orders.{png,pdf}` — phylum separation (the clean view)
Poincaré-metric UMAP of the final metazoa embedding, **one point per order** (≈700 order-level nodes),
coloured by phylum. Plotting one point per coarse taxon (instead of every species) removes the dominant
family-level micro-clustering and surfaces clean **phylum regions**: Chordata, Arthropoda, Echinodermata,
and Platyhelminthes resolve into distinct clusters; the smaller lophotrochozoan/cnidarian phyla sit in a
neighbouring group (their orders are genuinely closer in the embedding). This is the figure that answers
"do Arthropoda / Cnidaria / … separate?". Generated by the upgraded `scripts/figure_umap_taxa.py`
(rank-based colouring + `--node-rank` + balanced sampling; supersedes the depth-based
`visualize_multi_groups.py`):
```
.venv/bin/python scripts/figure_umap_taxa.py \
  --checkpoint artifacts/tags/metazoa_lower_lr_bigger_batch/metazoa_lower_lr_bigger_batch.pth \
  --mapping data/taxopy/metazoa_33208_clean/taxonomy_edges_metazoa_33208_clean.mapping.tsv \
  --rank phylum --node-rank order --metric poincare --n-neighbors 15 --min-dist 0.5 \
  --title "Metazoa embedding — phylum separation (one point per order)" \
  --out paper/figures/metazoa_umap_phylum_orders
```

### `metazoa_umap_minor_phyla.{png,pdf}` — the minor phyla, on their own
Companion to the order-level figure: `--exclude-taxids 6656 7711` drops the two giant phyla (Arthropoda +
Chordata) so the smaller ones get UMAP room. Echinodermata, Platyhelminthes and Annelida resolve into
clearly distinct clusters; Mollusca/Cnidaria/Porifera group but stay distinguishable — i.e. the central
"clump" in the all-phyla figure is a layout-crowding effect, not a failure to separate.
```
.venv/bin/python scripts/figure_umap_taxa.py --checkpoint <metazoa final> --mapping <metazoa mapping> \
  --rank phylum --node-rank order --exclude-taxids 6656 7711 --metric poincare \
  --n-neighbors 12 --min-dist 0.5 --out paper/figures/metazoa_umap_minor_phyla
```

### `metazoa_umap_phylum.{png,pdf}` — species-level (fine-rank purity)
Same embedding, every-species sample coloured by phylum. Shows the *other* true face of the embedding:
thousands of tight, **taxonomically pure** micro-clusters (every blob is one colour) — the visual
correlate of the family-level 10× separation. Phyla don't merge into single blobs here because the
fine-rank signal dominates; use the order-level figure above for phylum regions. (`--metric poincare
--cap-per-group 2500 --n-neighbors 50`.)

### `arthropoda_umap_class.{png,pdf}` — a different level (zoom)
`--restrict-to-taxid 6656 --rank class --node-rank family`: zooms into Arthropoda, one point per family,
coloured by class (Insecta / Arachnida / Malacostraca / Copepoda / …). Class structure is visible
(Copepoda and Arachnida form coherent groups) though Insecta's 1,275 families spread widely.
